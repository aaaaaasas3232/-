# 框架顶栏视觉断层问题

## 现象
当用户在 `appConfig.topbar.bg` 设置了非透明背景（例如 `solid` / `gradient` / `rgba(...)`）时：
- 状态栏会"悬空"在 nav bar 上方，**与 nav bar 形成视觉断层**
- 看起来像"状态栏把内容区横膈出来了"
- **iOS HIG（Human Interface Guidelines）要求状态栏与导航栏视觉一体**——这是设计语言层面的违反

## 截图位置
原 issue 来自 prompt-survey.js 的 topbar 预览 `/Users/Administrator/Desktop/小听启动/js/apps/prompt-survey.js`（已废弃，但问题在 prod framework 同样存在）。

## 术语
- 中文：**"顶栏视觉断层"** / "状态栏与导航栏脱节" / "状态栏悬浮"
- 英文：**Status bar / nav bar discontinuity** / **Status bar floats above navbar** / **iOS top bar visual break**
- iOS HIG 章节：**Bars / Navigation Bar / "Modifying the Prompt"** ——提到了状态栏的背景应与 nav bar 视觉一体
- 相关设计原则：**"Continuous Background"**（连续背景）

## 应有的修复方向
当 `topbar.bg` 设为非透明颜色时，状态栏所在的容器 **应当也涂上 topbar.bg**（让状态栏"坐"在 nav bar 背景里），而不是悬浮在上方。具体做法：
- 方案 A：状态栏容器与 nav bar 共享同一个父节点 + 背景
- 方案 B：状态栏不再独立容器，挪到 nav bar 顶部内嵌
- 方案 C：CSS 变量 `--topbar-bg` 同时驱动 statusbar + navbar 的 `background`
