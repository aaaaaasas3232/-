## 1. 小听是什么

**小听启动**是跑在浏览器里的 iPhone 模拟器，也是一套 AI 角色扮演手机。

打开后你会看到一台手机：状态栏、灵动岛、桌面图标、底部指示条。点图标就进 App。所有数据默认存在本机 IndexedDB，不经过项目自己的服务器。

它不是一个聊天框套皮，而是一整台「假手机」：

- 有桌面、锁屏感、手机壳、壁纸、状态栏时间
- 有钱包（红包、购物、发薪、机票走同一本账）
- 有世界观和纪时（叙事日期不要用现实的 `new Date()` 冒充）
- 有灵动岛、桌面小组件
- 桌面上有二十多个内置软件，内容大多按你绑的**世界观 + 人设**现生成

一句话：**听见另一个世界的声音，也听见你的声音。** 项目采用 [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/deed.zh-hans)，可自由二次修改，禁止商用。

## 2. 代码架构

### 2.1 技术栈（先记这几条）

- **Vite 5**：开发服务器和打包
- **Vue 3 是浏览器全局脚本**（`js/vendor/vue.global.prod.js`），**不是** npm 里的 `vue` 包
- 业务 App 是纯 ESM，只通过 `registerPhoneApp` / `registerPhoneAppAsync` 一个口子接入
- 样式：Tailwind + 各 App 自己的 `css/apps/<id>/`
- 持久化：IndexedDB（表的说明书在 `src/core/db-catalog.js`）
- 别名：`@/` 指向项目根

### 2.2 启动链

```
index.html                 手机外壳：状态栏 / 灵动岛 / 桌面 / App 窗
    ↓
src/index.js               拼 framework + 数据库 + 全部 App
    ↓
js/framework/              桌面、导航、灵动岛 runtime、小组件、presence-center
js/db/                     IndexedDB 底座
js/apps/index.js           ★ 所有内置 App 的 import + 注册顺序
js/apps/<id>/              各 App 源码
css/apps/<id>/             各 App 样式（index.html 里要有 <link>）
src/core/                  给 App 用的 SDK（注册、渲染、岛、DB、插件、资金）
```

冷启动：`registerAll()` 按 `appFactories` 顺序注册 → 声明了 `stores` 的必须 `async: true`（先建表）→ 桌面从「当前世界可见 + 已安装」画出图标。单个工厂抛错只跳过该 App，不中断全部。

### 2.3 目录怎么记

| 目录 | 干什么 |
|---|---|
| `index.html` | 手机壳 DOM、引入各 App CSS |
| `src/index.js` | 入口，不要为了加 App 改这里 |
| `src/core/` | 框架 SDK：注册、岛、插件、资金总账、主题 mixin |
| `js/framework/` | 桌面与运行时 hooks |
| `js/apps/index.js` | **唯一**内置 App 清单 |
| `js/apps/<id>/` | 某个 App |
| `css/apps/<id>/` | 某个 App 的样式 |
| `js/db/` | IndexedDB |
| `src/core/db-catalog.js` | 全表说明书（nook「数据库」页读这里） |
| `vite.config.js` | 日常开发 + 多文件打包 `dist/` |
| `vite.config.single.js` | 单 HTML 打包 `dist-single/` |

### 2.4 一个内置 App 长什么样

每个 App 是一个工厂函数，`default export` 后返回 `appConfig`：

- `id` / `name` / `icon`（icon 必须是内联 `<svg>`，否则桌面空白）
- `pages[]` + `defaultRootPageId`（后者必须落在 pages 里，否则打开白屏）
- `renderPage(page, state, app)`：**没有 `this`**，用第三参 `app`
- `renderMode`：`template` / `hybrid` / `vue`
- `methods`：必须写方法简写，禁止箭头函数（`this` 会丢，按钮点了没反应且不报错）
- 有表就要 `stores` + 在 `js/apps/index.js` 里 `async: true` + 去 `db-catalog.js` 登记

接入一个新内置 App 只改三处，不要改 `src/index.js`：

1. 写 `js/apps/<id>/index.js`
2. 在 `js/apps/index.js` 加 `import` + `appFactories`
3. 在 `index.html` 加 `<link rel="stylesheet" href="/css/apps/<id>/index.css?v=1" />`

### 2.5 跨 App 怎么说话

跨 App **不是** `import` 对方的 store。通道都是「声明 + 运行时 SDK」。少接一环的表现是：开关能点，但 AI / 岛 / 桌面完全收不到，而且零报错。

常见通道：

- **灵动岛**：先在 `islandKinds` / `notifyKinds` 声明，再 `toolkit.island.show` / `notify`，且必须带 `kind`
- **桌面小组件**：`widgets[]`
- **murmur 提示词卡**：在 `setup()` 里 `toolkit.prompts.register`（不要写在 `hydrate()`）
- **社媒形象**：`socialProfile`，nook 人设页自动多一张卡
- **世界可见性**：`worldAvailability`（演员 App 只在 actor 世界，电竞只在 esports）
- **钱**：只走 `window.settingsSdk.assetFlow`，禁止 App 自己再存一份余额
- **社交影响**：`registerSocialInfluenceProvider`（热搜 / 私信 / 评论风向）

### 2.6 三种渲染模式

| 模式 | 谁在用 | 注意 |
|---|---|---|
| `template` | 天气、商店页一类 | `renderPage` 返回 HTML 字符串 |
| `hybrid` | murmur | HTML + 少量 Vue 岛组件 |
| `vue` | 梦境、四叶草、点灯等大多数新 App | 框架**不会**自动 `hydrate()`，根组件 `mounted()` 里自己踢 |

### 3.2 Cursor 打包构建教程（多文件 → `dist/`）

用途：把项目打成网站那种多文件产物，用静态服务器打开，或给 `npm run preview` 预览。

1. 用 Cursor 打开文件夹 `小听启动`（要打开项目根，能看到 `package.json`）。
2. 打开终端：`` Ctrl+` ``，或菜单 Terminal → New Terminal。确认提示符在项目根。
3. 第一次先装依赖：

```bash
npm install
```

4. 开发时用热更新（改代码浏览器自动刷新）：

```bash
npm run dev
```

浏览器打开 `http://localhost:5173`。局域网手机可用同一 Wi-Fi 下的 `电脑IP:5173`（`vite.config.js` 已 `host: 0.0.0.0`）。

5. 要出「可部署的多文件包」时：

```bash
npm run build
```

产物在 `dist/`：`index.html` + `assets/` 等。这是普通 Vite 站点，**不能**指望双击 HTML 在 `file://` 下完整工作（相对路径和模块会断）。

6. 本地预览打包结果：

```bash
npm run preview
```

7. 可选自检：

```bash
npm test
npm run test:regression
```

对应配置是根目录 `vite.config.js`。一般不用改。

### 3.3 Cursor 建立单个文件教程（整台手机 → 一个 HTML）

用途：得到 **一个** `index.html`，用浏览器直接打开（`file://`），桌面、聊天、音乐岛、nook 资金与纪时都应能用。适合发给别人「双击就能玩」。

1. 同样在 Cursor 终端、项目根执行：

```bash
npm install
npm run build:single
```

2. 等终端出现类似 `单文件已写好，x.xx MB`。
3. 打开文件夹 `dist-single/`。**里面只该有 `index.html`**（顶多一个 favicon）。如果还有 `assets/*.js`，说明内联没收干净，不要拿去给别人。
4. 用 Chrome / Edge **直接打开**这个 `index.html`（可以拖进浏览器）。不要用「用 Live Server 打开」来验收单文件——验收的就是 `file://`。
5. 抽查：桌面图标在、nook 能建用户、murmur 能发消息、音乐能出岛、钱包流水能记。

对应配置是 `vite.config.single.js`。它会：

1. 把字面量 `import('./x.js')` 提升成静态 import，避免拆 chunk（否则 file:// 会 404）
2. 用 `vite-plugin-singlefile` 把 JS/CSS 内进 HTML
3. 把 Vue vendor、favicon、残留 link 收进 HTML
4. 把音乐岛 CSS 编译期打进岛模板
5. 设置 `window.__LISTEN_SINGLE_FILE__ = true`

插件上传、群聊自定义小游戏仍是运行时 `import(blob)`，这是故意的，单文件包不会把用户后来贴的 JS 预先打进去。

**不要做的事：** 不要用 Vite `define` 把整个标识符 `window.__LISTEN_SINGLE_FILE__` 替换成 `true`（会把赋值打成 `true = true`）。

---

### 3.4 补充：用 Cursor「新建一个单文件 App」

这里的「单个文件」指 **一个 App 只写一个 `.js`**，不是上一节的整包 HTML。

现成例子：天气就是 `js/apps/weather-app.js` 单文件。

最短路径：

1. 复制天气或 `relax-app` 的结构（新 App 更建议目录型，不要再堆成 1.3M 单文件）。
2. 在 Cursor 里改 `js/apps/index.js` 和 `index.html` 的 CSS link。
3. 有表就改 `db-catalog.js`，工厂加 `async: true`。
4. `npm run dev` 打开桌面看图标。

用户侧「粘贴一段 JS 变成桌面图标」走 **nook → 软件管理**，规则是：

- **一行 `import` 都不能有**（blob URL 解析不了别名）
- 依赖从 `window.settingsSdk` / `window.__apiSdk` / `window.__listenPresets` 拿
- 用 App 制作生成的白膜，也可以一键装到桌面（同一套 `plugin-installer`）

## 4. 第一次打开建议怎么走

按这个顺序，后面的世界生成 App 才有东西可长：

1. **nook → 顶部头像卡**：新建「我」（默认用户）。
2. **nook → API**：加一把能用的 Key，并给人设绑上（没有 Key，聊天和生成类 App 会空转或走本地兜底）。
3. **nook → 世界观**：新建世界。可从空白开始，或选预设「演员世界 / 电竞世界」。
4. 把默认用户 **绑定** 到这个世界（四叶草 / 候鸟 / 萤火等「按世界生成」的 App 认的是绑定，不会偷偷借用别人当前打开的世界）。
5. **nook → AI**：建几个人设。
6. 打开 **murmur** 新建对话，确认能回。
7. 再去逛四叶草、日记、氧气等。

演员玩法：世界模式选 **actor**，桌面会多出 **追光**，**灯塔**会藏起来。  
电竞玩法：世界模式选 **esports**，桌面会多出 **声浪、赛点**，**灯塔**同样藏起来。

## 5. 全系统共用的三件事

后面每个软件都会碰到，先放在这里，避免每个 App 重复解释。

### 5.1 钱包（同一本账）

人设钱包在 `persona.assetBalance` + `assetFlow[]`。

谁在用：murmur 红包/转账、四叶草购物、灯塔发薪、追光片酬、候鸟机票、声浪薪资奖金、定时收入。

货币名来自当前世界 `world.currencies` 里 `isBase` 那条，界面不要写死「元」或 `$`。

余额不足时支出会失败，不会透支。流水可在 **nook 人设主页的资产卡** 或 murmur「我 → 钱包」查看。

### 5.2 纪时

状态栏可切：真实时间 / 世界纪时 / 时差。

叙事日期必须来自世界钟。追光、声浪每档还有自己的档内时钟（快进整档一起走；到 24:00 会问「进入下一天 / 明天再玩」）。

### 5.3 世界观与档案键

很多 App **没有内置商品/职位/视频**。货架是打开后按「默认用户 + 绑定的世界」现问 AI 生成的。

数据按 `用户id::世界id` 分档：换用户或换世界等于换档案；换回来，旧档还在。

没绑世界时：日记的随笔、氧气的房间、点灯、小奇怪仍可用；四叶草/候鸟等会停在引导页。

### 6.1 nook（设置）· `settings`

**是什么**  
整台手机的后台。人设、世界、外观、API、图库、提示词、导入导出、数据库、插件都在这里。对外暴露 `window.settingsSdk`。

**功能（主页入口）**

| 入口 | 能做什么 |
|---|---|
| 顶部头像卡 | 当前默认用户；点进去编「我」 |
| 外观 | 手机壳颜色/材质、壁纸、状态栏显隐、时间颜色、5G 文案、电池、手机高度与垂直位置、隐藏手机壳 |
| 世界观 | 世界列表；标签；地点/地标；货币；纪时；锚点（节日等）；演员/电竞两套预设 |
| AI | AI 实例与人设卡（性格、经历、绑定 API） |
| 图库 | 收藏图、灵感、参考图组（萤火头像池会用到） |
| Prompt | 提示词模板与变量（`{{aiName}}` / `{{userName}}` 等） |
| API | 提供方、Key、模型、用量；没有「列出全部明文 Key」给业务乱扫的接口 |
| 导入与导出 | 角色卡、AI、世界观、Prompt 进出 |
| 数据库管理 | 按 `db-catalog.js` 浏览/编辑本机表、检查漂移 |
| 软件管理 | 上传或粘贴 JS 插件；启用/禁用/删除/导出 |

点进某个人设后还有 **人设主页**：概览、今日心情、周历日程、资产与定时收入、社媒形象（murmur / 氧气 / 萤火等 App 自己声明的卡）、当前会注入给 AI 的上下文预览。

**怎么用**

1. 先建用户，再建世界，把用户绑到世界。
2. 再在 API 页加 Key，回到人设页把 Key 绑上。
3. 外观页调手机壳和状态栏，直到你觉得「这就是我的那台」。
4. 要装自己写的 App：软件管理 → 选文件或粘贴 → 系统会先检查有没有 `import`、页面 id 是否对得上。
5. 「去配置货币」必须先把当前世界切到该人设绑定的世界，再打开世界观页（不要跳不存在的子页）。

**注意**  
nook 本身几乎不生成故事。它只把「我是谁、世界是什么、用哪把钥匙」准备好。

### 6.2 murmur（聊天）· `chat`

**是什么**  
和人设过日子的主场。私聊、群聊、动态、通话、红包/转账都在这里。底栏四个 Tab：**消息 / 通讯录 / 动态 / 我**。

**功能**

- **消息**：会话列表；顶栏可切记录模式（普通时间线 / 故事感）
- **私聊**：文字、表情、语音条、引用、拍一拍、特殊动作（红包、转账、音乐卡、一起听）
- **群聊**：成员数 = `members.length + 用户`（两个 AI 的群是 3 人）；可设管理、群公告、备注；可切换「我以谁的身份发言」
- **群聊小游戏**：在游戏页上传一段 JS（不能有 `import`），战绩卡类型是 `game_record`
- **通话**：语音可最小化到灵动岛（正在通话不允许关岛）；视频不支持最小化
- **来电 / 新消息**：不在该会话时走 compact 岛通知
- **通讯录**：搜索人设、签名
- **动态**：朋友圈式信息流；外收藏+分享，左滑编辑/删除
- **我**：头像与 murmur 社媒形象、收藏、钱包流水、拍一拍文案、群聊记忆互通、灵动岛与小组件总览

- 每档独立时钟：早中晚、快进、跨日询问
- 每档 30 位 NPC，JS 确定性拼装，不烧 token，跨档共享名册
- 突发事件：分线曲线 × 属性护盾 × 公关护盾 × 状态，seed 存档可回放；演出与阶段结算不重 roll
- 剧本可来自梦境书架或行业递来；试镜、演出
- 片酬 / 通告 / 奖金 / 公关费走 assetFlow
- 大事记；major 同步到世界观时间轴（删档回收）
- 奖项/节日同步世界锚点
- 影响氧气热搜、萤火私信/评论风向
- 风险面板能看到每项事件此刻的真实概率

**怎么用**

1. nook 用预设「演员世界」或把模式设为 actor，绑定默认用户。
2. 打开追光走完六步再进主界面。
3. 「今日」看日程和风险；「剧组」接戏试镜；「圈子」维护 NPC。
4. 快进会让整档纪时一起走，不能靠重进刷好结果。

### 6.21 声浪（电竞论坛）· `esports-forum`

**是什么**  
电竞世界的论坛，也是生涯与赛季的**事实源**。只在 **esports** 世界出现。底栏：**首页 / 板块 / 评分 / 我的**。

**功能**

- 七步首配：身份、项目、起点、加点、战队、锚点、开档
- 联盟名册：18 战队，确定性拼装，零 token
- **SAB 赛季**：三轮常规 + 卡位赛 + 双败季后赛；掷签带 seed
- 论坛日常帖/官博/评分/串子小号：零 token；点「热闹一下 / 生成评论 / 锐评 / 赛报」才调 AI
- 最多 5 个匿名马甲；约三成选手也有会改名的小号
- 你发的帖默认匿名，murmur 里的 AI 不知道马甲是你
- 月薪、赛事奖金走 assetFlow
- 队友互关、战队官博会描述到氧气/萤火（可在「我的 → 社媒联动」精确开关）
- 赛点通过 registry 调这里的 services，不互相 import store

**怎么用**

1. 绑电竞世界 → 七步开档。
2. 日常看板块和评分；NPC 比赛每天自动打完。
3. 轮到你出战，去 **赛点**。
4. 快进跳过的比赛由系统按当时状态代打，结果照进积分榜。

### 6.22 赛点（电竞客户端）· `esports-game`

**是什么**  
打排位和正式赛的地方。档、属性、赛程、薪资都在声浪。底栏：**大厅 / 赛程 / 好友 / 群聊 / 我的**。

**功能**

- 必须先在声浪开档，否则进不去
- 排位：单排到五排、连打局数、可带 AI/队友；一批结果一次掷定，逐局翻开，**没有重 roll**
- 时间与精力真实消耗；跨过饭点不吃有战力惩罚；一天 rank 不完 15 局，先见底的是时间
- 对局详情「云端文字回放」才调 AI
- 赛程「今日出战」：选赛前策略，奖金入账，赛后楼开在声浪
- 战队群：教练训练安排；没打训练赛会点名；可发起复盘
- 亲密值到 60 可挂情侣标（双方主页；解绑掉 20 点）
- 互关可见 rank 概要；具体对局内容看不到，除非分享
- 战绩可分享进 murmur；与 AI 开黑的概要只有当事 AI 知道
- 声浪没开着也能排位，概要进待同步队列，回来在「我的」一键重试

**怎么用**

1. 先开声浪的档。
2. 大厅选模式开打，翻局，不要指望重来。
3. 正式赛去赛程 Tab。
4. 想看发生了什么再点回放。

### 6.23 点灯（学习）· `starlit`

**是什么**  
学的是「它为什么诞生」，不是词表。不挑世界观：老师可以是世界里的 AI，也可以是模型本身。底栏：**主题 / 课程 / 推理墙 / 词典 / 我的**。

**功能（一条完整的路）**

1. 建主题（语言或代码）
2. 摸底问卷 → 水平侧写 → 你定终点 → 排课
3. 上课：老师边讲边吐卡片 / 词条 / 卡住点（```` ```starlit ```` 技能块）
4. 下课：收成卡片网，覆盖更新侧写
5. **反转课堂**：你当老师，AI 当「上课前那个水平」的学生，**它不知道课文内容**，下课按钮在它手里
6. 推理墙：拖卡、拉红线、叠卡、分块、整理（纯几何，不调 API；太多卡会退回网格）
7. 词典三种找上你：弹幕（挂在手机屏幕上）、灵动岛、手机壳外小电视（可当单词机）

语言模式额外：

- 浸没：主题上选全外文或按课程序号升档
- 一条回复拆多个短气泡
- 翻译形态：描边贴边 / 点开翻译；长按翻译（本地词典或只发这张卡）

代码模式：每行可长按改；预览窗一个看效果，一个看页面从空白长出来。

其它：卡片跨课复用（同一概念墙上只有一张）；整理墙/弹幕/改卡不调 API；没有任何定时器会偷偷打 AI。

**怎么用**

1. 「主题」新建，选语言或代码、选老师。
2. 老实答问卷，再定终点。
3. 「课程」点开一节再上课（详细内容不会提前写好）。
4. 说「我没懂」会记进错题本并改路线。
5. 上完去推理墙连线；想检验自己就开反转课堂。
6. 词典里打开弹幕或小电视，让词自己回来。

### 6.24 小奇怪 · `oddity`

**是什么**  
旧原型箱子。底栏四个抽屉：**玩 / 捏 / 看 / 藏**。（商店文案有时写「字」，当前代码第四个是「藏」。）

**功能**

| 抽屉 | 里面有什么 |
|---|---|
| 玩 | **扫雷**（9×9、10 心、点扫、长按插旗、第一下不炸、轮流 +1/−5）；**五子棋**（15 路）；**你有我没有** |
| 捏 | **粉红果冻心**：戳会疼、摸会暖；工具组、听心声、投喂、切人设、收藏瞬间 |
| 看 | **沙漏**（正放表面话，颠倒露潜台词）；**打字机**（写下又删的草稿）；**回答箱 / 收信箱 / 漂流瓶** |
| 藏 | 收藏夹：筛选、复制、动效回放 |

棋类：

- 对手可以是本地真人或 nook 的 AI
- AI 只回坐标；没 Key 或不合法 → 本地棋手兜底，**局不卡死**
- 终局可分享到 murmur（复用 `game_record` 卡）
- 提示词库可注入对局
- 战绩变化会同步 murmur 动态提示词卡
- 开局/终局走岛 `oq-match`，踩雷走 `oq-sweep`

**怎么用**

1. 「玩」里开扫雷或五子棋，选对手。
2. 没配 API 也能下，只是 AI 话少、走本地棋力。
3. 打完分享到 murmur。
4. 「捏」「看」当解压和心事，收藏进「藏」。

### 6.25 App 制作 · `app-maker`

**是什么**  
把「我想要个什么样的 App」问清楚。同一份蓝图产出两样：**能点的白膜** + **按配置现算的提示词**。底栏：**词汇 / 配置 / 助手 / 生成**。

**功能**

- 词汇：框架名词科普
- 配置：问卷（页面、导航、数据、弹窗、岛、小组件、购物/求职/五子棋/贪吃蛇/跨时空等能力项，按勾选裁剪提示词）
- 助手：用已绑的 API 帮你把需求说清楚
- 生成：白膜源码 + 提示词；可装到桌面；岛提示「生成完成 / 装好了」
- 配置体检：缺页、缺 id 会先报，避免白屏
- 草稿防抖保存

**怎么用**

1. 「配置」一步步填，角标显示第几步。
2. 不懂词就切「词汇」。
3. 「生成」先看白膜能不能点。
4. 把提示词交给 Cursor 或其它模型，在白膜上填真逻辑。
5. 「装到桌面」走和软件管理同一套插件安装器（白膜同样不能有 `import`）。

这就是目前仓库里**最接近「用 Cursor 从零建 App」的官方向导**。独立的 `docs/提示词-从零生成App.md` / `docs/提示词-HTML转App.md` 目前不在仓库里。
