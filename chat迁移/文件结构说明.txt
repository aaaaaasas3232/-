## 四、page 对象支持的字段

| 字段 | 类型 | 用途 |
|------|------|------|
| `id` | string | 页面唯一标识 |
| `label` | string | tab-bar 显示名 |
| `iconHtml` | string | SVG icon (走 v-html) |
| `icon` | string | 单字符 fallback (走 escape) |
| `nav` | boolean | 是否出现在 tab-bar |
| `topbar` | object | 页面级 topbar |
| `type` | string | `'detail'` 表示详情页 |

## 五、Framework 侧相关文件

若需修改 framework 行为，关注以下文件：

```
js/framework/
├── use-app-navigation.js     ← page.topbar 优先级逻辑
├── core-shim.js              ← escapeTabIcon 方法
└── ...

src/core/
├── app-renderer.js           ← 三模式渲染调度器
├── island-components.js      ← 内置 island 组件
└── ...
```

**Framework topbar 优先级**:
```
page.topbar > app.topbar > window.__appTopbarOverride
```

**合并逻辑** (用 spread merge 保留字段):
```javascript
const base = pageTopbar ? { ...appTopbar, ...pageTopbar } : appTopbar;
```
