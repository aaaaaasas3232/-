## 上下文关联

这些功能强依赖以下外部接口(均位于 chat.js 之外,实际接入时需要替换):

- `PhoneCore` —— 全局命名空间,提供 `getAI / saveAI / getApp / apps / user / transactions / notifications / db / time / resources` 等
- `DynamicIsland` —— 通话时联动灵动岛
- `MusicPlayerState` —— 一起听音乐状态
- `startListenTogether` —— 全局函数,启动一起听
- `EventBus` —— 跨模块事件总线(用于匿名短信等)
- `ai.transactionHistory` / `user.balance` —— 用户与 AI 资金账户
