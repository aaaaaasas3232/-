  「我的捏捏」示例代码

编辑页最上面那栏「做法」有三档,自由度依次递增:

  格子板   只写一格的样子,板子自动复制铺满。气泡纸、巧克力那种。
  自由做   整块画一个东西,不复制。交互靠 data-hb 标记,不写 JS。
           摇杆、鼠标、旋钮、控制盒都属于这一档。
  写代码   HTML + CSS + JS 三样全放开,跑在一个隔离的沙箱里。
           想做什么做什么 —— 有物理、有随机、有累积状态的东西只能用这档。

本文件里:例 1~3 是「自由做」,例 4~5 是「写代码」。


────────────────────────────────────────
怎么用这个文件
────────────────────────────────────────

1. 解压角 →「捏捏」→ 点「我的捏捏」→ 点「写 HTML / 换模板」
2. 最上面那栏「做法」,选对应的那一档(每个例子标题上写了)
3. 从下面挑一个例子,把它下面的那几个 ``` 代码块整段选中复制
   (连着 ``` 一起复制没关系,不用自己拆)
4. 切到「让 AI 帮忙」那一栏,拉到最下面的「把 AI 的回复贴回来」,
   粘进去,点「拆开填进编辑器」
5. 会自动跳回「改代码」。预览那块是**真的能玩的** —— 直接在编辑页里试
   (「写代码」那档改完 JS 要自己点一下「重新运行」)
6. 满意了点「应用到主体」,再点左上角「返回」

  第一部分:自由做

────────────────────────────────────────
五种零件(打在自己的元素上)
────────────────────────────────────────

data-hb="press"    按钮。按住给 --hb-p(0/1),按住时加 .is-press
data-hb="toggle"   开关。点一下翻面,给 --hb-on,加 .is-on。会存档
data-hb="stick"    摇杆。拖动给 --hb-x / --hb-y(-1~1),松手自动回中
data-hb="slide"    滑块。拖动给 --hb-x / --hb-y(0~1),停在原地。会存档
data-hb="dial"     旋钮。绕中心转,给 --hb-deg(累计角度)。会存档

拖动中的零件会带 .is-active。


────────────────────────────────────────
三条最容易踩的坑
────────────────────────────────────────

1. 变量都是**纯数字**,自己乘单位,而且要带兜底值:
       transform: rotate(calc(var(--hb-deg, 0) * 1deg));
       transform: translateX(calc(var(--hb-x, 0) * 50%));
   不带兜底的话第一帧变量还没写进去,整个 calc 会失效。

2. 盖在零件上面的装饰层,一律写 pointer-events: none。
   高光、刻度、中缝这些挡住手指的话,那块就「怎么按都没反应」。

3. 摇杆的 data-hb 打在**底座**上,不是帽子上;帽子要 pointer-events: none。
   而且 .is-active 时要把帽子的 transition 关掉,否则手指走一步、帽子晚半拍。


────────────────────────────────────────
还能加的属性
────────────────────────────────────────

data-id="left"        给零件起名。存档按它对号入座,别的元素也能读到
                      镜像变量 var(--hb-left)。**建议每个都写**
data-axis="x|y|xy"    只给 slide,选能拖的方向。默认 xy
data-step="0.1"       每走这么多响一下。slide 填 0~1 的比例,
                      dial 填角度,stick 填方向数(比如 8)
data-wrap             只给 slide。拖到头从另一头绕回来(滚轮靠它)
data-gain="0.4"       只给 slide。零件很小就调小,不然一碰到底
data-min / data-max   只给 dial。限位,单位是度
data-once             只给 press。按过一次永久留 .is-popped,存档
data-hold             只给 press。按住不放一直出声一直震
data-release          只给 press。松手再响一声
data-rate="1.3"       这个零件的音调。1 是原声
data-mute             这个零件不出声
data-heavy            震得重一点


────────────────────────────────────────
能直接用的其他变量
────────────────────────────────────────

--hb-unit             这块区域的短边长度(带 px)。所有尺寸都从它算,
                      别写死 px,也别用 width:70% + height:70% 撑圆形
--htmlbubble-tint     用户在「捏捏」面板里选的主题色
--rx-ease-bounce      全局的弹性缓动曲线,做回弹用它

════════════════════════════════════════════════════════════
  第二部分:写代码
════════════════════════════════════════════════════════════

这一档 HTML / CSS / JS 三样全放开,跑在一个 <iframe sandbox> 里。

────────────────────────────────────────
沙箱是什么意思
────────────────────────────────────────

你的代码在一个**独立的页面**里跑,和小听不同源。所以:

  · 它读不到你的聊天记录、存档、界面 —— 就算是从别处粘来的代码也翻不到
  · 它完全上不了网:fetch、外部图片、外部字体、CDN 上的库全都被拦
  · 要出声、震动、存档,只能走下面这个 hb

页面结构是固定的,外层不用你写:

    <body>
      <div id="stage">   ← 你的 HTML 放这儿,也就是 hb.el
      </div>
    </body>

#stage 已经铺满画布、居中、清好边距、禁掉了长按选词。

────────────────────────────────────────
hb —— 和外面说话的唯一通道
────────────────────────────────────────

  hb.el                       你的容器(#stage)
  hb.width / hb.height        画布当前像素尺寸
  hb.unit                     画布短边,按比例算尺寸时用
  hb.tint                     用户选的主题色;CSS 里是 var(--tint)
  hb.sound({ rate })          播一次音,rate 是音调(1 是原声)
  hb.haptic('light'|'medium'|'heavy')    震动
  hb.notify(标题, 内容)       走顶上的灵动岛。别频繁调
  hb.state                    存档对象,一进来就有值
  hb.save({ 键: 值 })         写存档,浅合并 + 自动防抖
  hb.on('resize', fn)         画布尺寸变了(canvas 要在这里重设宽高)
  hb.on('tint', fn)           用户换了主题色

CSS 里另有 var(--tint) 和 var(--hb-unit)。

────────────────────────────────────────
三条会让你踩坑的
────────────────────────────────────────

1. **绝对不要写 while(true) 或 for(;;)。**
   沙箱和界面共用一个线程,死循环会把整个 App 卡死,只能杀掉重开
   (存档不会丢,但当下什么都点不动)。要持续动画一律用
   requestAnimationFrame。

2. **一秒最多放 24 声。**
   超了会被丢掉。别在每一帧里 hb.sound(),只在「真的发生了什么」时响。

3. **canvas 记得乘 devicePixelRatio,并且在 hb.on('resize') 里重设宽高。**
   不然在手机上是糊的,转屏之后还会错位。

```js
    // 重播动画:先摘类、强制重排、再加回去
    fish.classList.remove('is-hit');
    void fish.offsetWidth;
    fish.classList.add('is-hit');

    hb.sound({ rate: 0.88 + Math.random() * 0.28 });
    hb.haptic('medium');
    hb.save({ n: n });

    if (n % 108 === 0) hb.notify('功德 +1', '已经敲了 ' + n + ' 下');
});
```

```js
var die = hb.el.querySelector('.dc-die');

// 九宫格的九个点,按点数决定亮哪几个
var PIPS = {
    1: [4],
    2: [0, 8],
    3: [0, 4, 8],
    4: [0, 2, 6, 8],
    5: [0, 2, 4, 6, 8],
    6: [0, 2, 3, 5, 6, 8]
};

var cells = [];
for (var i = 0; i < 9; i += 1) {
    var pip = document.createElement('span');
    pip.className = 'dc-pip';
    die.appendChild(pip);
    cells.push(pip);
}

function show(n) {
    var on = PIPS[n] || PIPS[1];
    for (var i = 0; i < 9; i += 1) {
        cells[i].style.opacity = on.indexOf(i) >= 0 ? '1' : '0';
    }
}

var value = hb.state.value || 1;
show(value);

var rolling = false;

function roll() {
    if (rolling) return;
    rolling = true;
    die.classList.add('is-rolling');

    var ticks = 0;
    // ★ 用 setInterval,不是 while 循环 —— 循环会把整个 App 卡死
    var timer = setInterval(function () {
        ticks += 1;
        show(1 + Math.floor(Math.random() * 6));
        hb.sound({ rate: 1.25 + Math.random() * 0.5 });
        hb.haptic('light');

        if (ticks >= 9) {
            clearInterval(timer);
            value = 1 + Math.floor(Math.random() * 6);
            show(value);
            die.classList.remove('is-rolling');
            rolling = false;
            hb.sound({ rate: 0.68 });
            hb.haptic('heavy');
            hb.save({ value: value });
        }
    }, 80);
}

die.addEventListener('pointerdown', roll);
```
