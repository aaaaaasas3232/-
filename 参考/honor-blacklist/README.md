# 王者荣耀云黑网站 - 前端项目

## 设计风格
- 无印良品简约风 + iOS磨砂玻璃
- 主色调：暖黄色 (#FFD60A / #FFCB3D)
- 无emoji，纯SVG图标设计
- Q弹流畅动效

## 页面说明

| 页面 | 文件 | 功能 |
|------|------|------|
| 首页/搜索 | index.html | 主入口，搜索游戏ID |
| 提交页面 | submit.html | 用户提交云黑信息 |
| 结果页面 | result.html | 展示查询结果 |
| 审核登录 | admin-login.html | 审核组登录 |
| 审核后台 | admin.html | 审核管理面板 |

## 状态说明
- 当前为纯前端版本，数据使用 localStorage 模拟
- 后端接口后续对接

## 运行方式
直接用浏览器打开 index.html 即可
